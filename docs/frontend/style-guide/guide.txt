THE RULES
A stack of sections is ONE framed object. Each section is a band inside it.
The group owns the seam: > * + * — never :nth-child, which stops matching the moment a band is added or hidden.
Members draw NO frame of their own. Press the button and watch each join double from one line to four.
The group sets --edge-pad: 0; bands own their padding.
Every band leads with the same header row. A header that labels rather than toggles is a div, never a button — a section that cannot collapse must not advertise the affordance.
A band's tooltip is a SIBLING of the toggle, never nested inside it.
One disclosure marker, and it ROTATES. Open a band above and watch it turn 90 degrees and go cyan. Swapping the triangle for a second glyph is banned.
Never restate the band classes in scoped component CSS. Scoped rules are unlayered and out-specify @layer components, so a local copy wins silently and that one band drifts from every other.
CORNERS ON AN INTERIOR SEAM
--EDGE-BR: 0
--EDGE-TL: 0
square whichever corner lands on a seam · the pair shares one frame via margin-left: -1px
