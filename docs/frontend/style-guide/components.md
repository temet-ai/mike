# Style guide patterns and their components

A page is built by importing these. A page does not restyle a button, a heading, an
error banner or a form control in its own `<style>` block.

Storybook renders every one of these from the real component. `scripts/story-shot <word>`
lists the stories that match, and with `--shot` saves a picture of each that the Read tool
opens. It needs Storybook running: the stack keeps it up as `mike-stack-storybook` (`systemctl --user start mike-stack-storybook`; without systemd: `cd frontend && pnpm run storybook`).

The whole guide, drawn with these components, is the story **Foundations/Style Guide**:
`scripts/story-shot --shot foundations style guide`. The Home and Sessions page patterns are
in **Foundations/Style Guide Pages**.
