# The Rust Service Playbook

Lessons for building a new Rust service, drawn from building mike. Start with
[`PLAYBOOK.md`](PLAYBOOK.md): it introduces the playbook and links each chapter in
[`parts/`](parts/), followed by [`case-studies.md`](case-studies.md),
[`appendix-a-adopt.md`](appendix-a-adopt.md) and
[`addendum-b-temet-proxy.md`](addendum-b-temet-proxy.md).

[`index.html`](index.html) is the same text as one page that works offline, with the
diagrams drawn. Open it in a browser from a checkout; GitHub shows it as source. Rebuild
it with `node docs/rust-playbook/build-html.mjs` after changing the Markdown.
