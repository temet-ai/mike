## Reading the status

- **Implemented**: a corresponding source change exists. This does not mean its final tests, database integration, or live behavior have passed.
- **Source already fixed**: relevant behavior was present on reviewed main; branch changes may clarify its contract.
- **Partial**: source mitigates part of the issue, while an explicit acceptance requirement remains.
- **Remaining**: no implementation of the requested capability is established here.
- **Withdrawn / outside fleet**: retained for inventory completeness, not represented as a code fix.

Paths prefixed `fleet/` below mean `crates/mike/src/launch/fleet/`. Other paths are repository-relative. Test filenames identify regression evidence available in source, **not an assertion that every listed test has executed**.
